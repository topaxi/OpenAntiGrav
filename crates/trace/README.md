# oag-trace

Compares a simulation run against a per-tick trace captured from the original,
and reports how they differ. Also the `oag-trace` command line (`show`, `run`,
`compare`, `script`, `drive`, `track`).

The reading half of the verification harness; capture is a script under `scripts/`.
See [oag-trace](../../docs/tools/oag-trace.md).
