# oag-source

Finding a title's disc image, opening it as whichever title it is, and
mounting downloadable content and the override and fallback layers around its
archives. A race's track and craft sources are opened here too.

It knows every title package, which `oag-title` deliberately does not, and knows
no race, menu, window or settings file. The boot, the sound host and the race load
can each open a source without depending on one another.
