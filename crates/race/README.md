# oag-race

Race rules: the mode, the lap count and how far round the course a ship has got.
Lap counting is a convention written down with its reasoning, because the original
shows no lap logic ([lap counting](../../docs/gameplay/lap-counting.md)).

Simulation code under the [determinism rules](../../docs/architecture/determinism.md).
Reads track data through `oag-vex` and `oag-tables`.
