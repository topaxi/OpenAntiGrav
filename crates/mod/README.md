# oag-mod

Mods: a folder, a `.zip` or a `.oagmod` read in place, the `oag-mod.toml`
manifest it carries, the search path and the built-in `oag-extras`.

Knows no menu and no title; the crates that read a mod's files decide what they
mean. Format: [mods](../../docs/tools/mods.md) and
[ADR-0066](../../docs/architecture/adr/0066-the-menu-is-the-disc-plus-mods.md).
