# oag-title

The engine-side types a title package fills in: archive candidates, entry
names and the foreign-serial deny-list. Types only, no game's constants.

`oag-pulse`, `oag-pure`, `oag-hd`, `oag-2048` and `oag-omega` supply the data.
Per-title behaviour is data on these types, not a branch in generic code
([ADR-0022](../../docs/architecture/adr/0022-title-packages.md)).
