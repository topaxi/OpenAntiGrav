# oag-present

What happens to a frame between the scene and the glass: the upscale blit and
composite, grade and screen filter, dynamic resolution scaling and the performance
meter.

Knows no race, menu or settings file; the host passes plain data in. Built on
`oag-display`, `oag-gpu`, `oag-post`, `oag-ui` and `oag-title` (the types of a title's
own width throttle).
