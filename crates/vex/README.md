# oag-vex

The `.vex` scene tree and the class-tagged payloads authored inside or beside
it: geometry, collision, the AI spline, pads, visibility sets, fog, lights,
sound emitters, shadow hulls and more. Which schema a file uses is read from its
own version word, never from the caller's idea of the title.

Counterpart of `oag-rcs`. Track and payload notes are under
[formats](../../docs/formats/README.md).
