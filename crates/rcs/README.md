# oag-rcs

The `RCSMODEL` scene that PS3, Vita and PS4 titles ship their geometry in:
models, materials, visibility sets and shader programs. The model and its material
table refer to each other, so they are one crate.

Counterpart of `oag-vex`, which holds the PSP and PS2 scene. Format notes:
[format status](../../docs/formats/README.md).
