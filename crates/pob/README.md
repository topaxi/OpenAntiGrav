# oag-pob

The `.pob` particle system: a `SYSP` container around a tree of emitters, their
channels, modifiers and embedded sprites. It only decodes. `oag-fx` plays what it
reads.

Depends on `oag-formats` and `oag-bytes` and no other workspace crate. Layout and
evidence: [pob format](../../docs/formats/pob.md).
