# Pure's SINGLE PLAYER is the disc's chain; what stays open

## Open

- **2026-10-12 `pure-campaign-authored`: landed.** The main menu's top row on Pure is SINGLE PLAYER (the existing `open_campaign` row, reworded per title by `Campaign::main_row`) and opens the disc's own chain: `Single Player` (Arcade, Tournament, Time Trial, Zone, Free Play), `Class Selection`, `League Selection` or `Tournament Selection`, `Track Selection` or `Zone Track Selection`, then `Team Selection`. The order is read off the screens' redirects (`oag_tables::pure_flow`, ground truth on both pressings); the last pre-race screen names one of the 32 events a class, which launches as a campaign cell and records into `[[campaign]]`. The earlier chosen list panel is deleted. Permanent write-up: `docs/formats/pure-campaign.md` (the chain, the class gate) and `docs/architecture/menus.md` (the row's wording, for `menu-mods`); the recovered law: `docs/ghidra/functions/psp-pure-usa/campaign.md`.
- **The class gate's later classes.** A fresh profile offers Vector and Venom (data: `Campaign::classes_at_start`, PPSSPP capture 2026-09-10). Flash, Rapier and Phantom are rewards in the original (`Unlock Flash Class` etc., a reward-name table at `0x08ab4a0c` read by the reward reveal `0x08951538`); **what raises them was not traced**, so this build opens a class on any tournament medal in the one before (chosen, not measured, `Chain::classes_offered`). To close it: a PPSSPP memory watch on the profile word the reveal reads, after a first tournament medal in Venom, or a decompile of the code that fills the class menu's `DisableEntriesBitField` (parsed at `0x088c76a0`).
- **What the original's screens show.** `Track Selection`, `League Selection` and `Tournament Selection` author an empty menu the code fills; whether the original draws medals, locks or requirements on them was not captured (no fresh-profile capture past `Class Selection` and `Team Selection`). The panel, the lock word, the medal inks and the context line are chosen. A PPSSPP walk with a medal earned would settle it.
- **`Class Selection`'s stat-graph art** (`class_background.mip`, `classgraph.mip` and the per-class `<class>graph2.mip`/`graph3.mip`, all eleven resolve) is authored beside the menu and is not drawn here.
- **Free Play** is a plain race with no record (chosen): the disc names the mode and "Free play session results" and no medal law reaches it. Its `Team Selection` Back returns to the race box's track screen, not the chain.
- **`MedalCount`'s counter.** `Medal_Evaluate` raises gold/silver/bronze counters (`+0x7c`/`+0x78`/`+0x74`) on every award, repeat or not; whether the `MedalCount` check sums them and whether a replay counts again was not traced. The chain counts each event's best medal once (chosen). A live PPSSPP check: earn one medal twice and read `MedalCount`'s operand.
- **Pure's own opponent in the campaign** is wired by the `pure-orig-driver` lane (`Title::race.original_opponent`); a campaign race is already marked as a campaign cell, so nothing here changes for it.
- **The race box does not gate.** Pure's Track Selection and Team Selection filter by the same unlock rows in the original in every mode. Only the chain and `Team Selection` (via `pure_locked_teams`) read them here; the race box's circuit list does not drop a Classic or Zone circuit until its medal count is met. `oag_game::unlock::Gate` is the place if the maintainer wants it.
- **Pure has no EndRace screens here, so a finished race shows the built-in results table.** `endrace_style: None` on Pure; the table's Cross/Start (or a click) is the way out: a single event returns to the chain on the screen that picked it, and a tournament with a leg to go advances to it. Pure's own end-of-race screens (`Race Complete`, rewards, a standings table) are unread.
- **The tournament medal is judged on the last leg only**, as `Medal_Evaluate` does; Esc after any leg abandons the series. The last leg's medal through the window is unwalked (the headless `pure_chain_walk_ground_truth` covers all four legs and the rank).
- **Time trial laps.** `RaceTimes` is a whole-race figure; the chain races the mode's default (three). A Pure capture of a time trial's lap counter would settle it.
- **No sound on the chain's own events beyond the menu cues**; Pure's `FE` name voices are not wired.
